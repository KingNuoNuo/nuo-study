# 服务端运行时依赖 —— 单家庭私有部署，给下限不强钉死，方便随系统 Python 走
#
# 装法（NAS）：
#   python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
#
# 说明：
#   · uvicorn 刻意不带 [standard] 后缀 —— 那个会拉 httptools/uvloop，
#     在无编译环境的机器上会卡在 build，单家庭这点流量用纯 ASGI 完全够。
#     真要提速再换 uvicorn[standard]（需 gcc + python3-dev）。
#   · python-multipart 是 FastAPI 解析 multipart/form-data 的硬依赖
#     （上传作业截图走的就是它），漏装会在启动时报 RuntimeError。
#   · Pillow 只用于上传前压缩大图；recognizer.py 里是 try-import，
#     确实装不上也不会崩，只是 12MB 的原图会被原样送去识别（更贵更慢）。
